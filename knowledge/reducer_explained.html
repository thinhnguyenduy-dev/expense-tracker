🔄 Reducer trong LangGraph - Giải Thích Chi Tiết

💡 TL;DR - Reducer là gì?

Reducer là một function quyết định cách merge (gộp) giá trị mới vào giá trị cũ của một field trong State.

  • ✅ Với Reducer: Giá trị mới cộng dồn vào cũ (merge)
  • ❌ Không Reducer: Giá trị mới ghi đè cũ (overwrite)

Trong LangGraph, dùng Annotated[Type, reducer_function] để định nghĩa Reducer.

📚 1. Khái Niệm Cơ Bản

Reducer trong Programming

Reducer là pattern phổ biến trong functional programming:

# Ví dụ Python: reduce function from functools import reduce numbers = [1, 2, 3, 4, 5] # Reducer: Cộng dồn các số result = reduce(lambda acc, x: acc + x, numbers, 0) # acc (accumulator) = giá trị tích lũy # x = giá trị mới # Kết quả: 0 + 1 + 2 + 3 + 4 + 5 = 15

Công thức chung:

new_state = reducer(old_state, new_value)

🎯 2. Reducer trong LangGraph

Mục Đích

LangGraph dùng Reducer để quyết định cách cập nhật State khi nhiều nodes return cùng một field.

Vấn Đề Cần Giải Quyết:

# Node A return: {"messages": [msg1, msg2]} # Node B return: {"messages": [msg3]} # ❓ State cuối cùng có gì? # Option 1 (OVERWRITE): [msg3] ← Mất msg1, msg2! # Option 2 (MERGE): [msg1, msg2, msg3] ← Giữ hết!
✅ Giải pháp: Dùng Reducer để merge thay vì overwrite!

📝 3. Syntax trong LangGraph

from typing import Annotated, List import operator from langchain_core.messages import BaseMessage class AgentState(TypedDict): # ✅ Có Reducer - Merge messages messages: Annotated[List[BaseMessage], operator.add] ↑ ↑ Kiểu dữ liệu Reducer function # ❌ Không Reducer - Overwrite next: Optional[str] clarification_needed: Optional[str]

Giải thích:

  • Annotated[Type, reducer] - Gắn metadata vào type hint
  • operator.add - Built-in Python function: a + b
  • LangGraph tự động gọi: operator.add(old_messages, new_messages)

1 Node A thực thi

State hiện tại: {"messages": [AIMessage("Hello")]}

⬇️
2 Node B thực thi
def node_b(state): return {"messages": [AIMessage(content="World")]}
⬇️
3 LangGraph Merge (với Reducer)
# LangGraph tự động gọi: new_messages = operator.add( state["messages"], # [AIMessage("Hello")] update["messages"] # [AIMessage("World")] ) # Kết quả: [AIMessage("Hello"), AIMessage("World")]

State cuối: {"messages": [AIMessage("Hello"), AIMessage("World")]}

✅ Messages được cộng dồn! Không mất dữ liệu cũ.

🆚 5. So Sánh: Có vs Không Reducer

❌ Không Có Reducer

class State(TypedDict): messages: List[BaseMessage] # ↑ Không có Annotated

Behavior:

Node A: {messages: [msg1, msg2]} Node B: {messages: [msg3]} ━━━━━━━━━━━━━━━━━━━━━━━ Result: {messages: [msg3]} ↑ GHI ĐÈ - Mất msg1, msg2!
⚠️ Vấn đề: Lịch sử conversation bị mất!

✅ Có Reducer (operator.add)

class State(TypedDict): messages: Annotated[ List[BaseMessage], operator.add ]

Behavior:

Node A: {messages: [msg1, msg2]} Node B: {messages: [msg3]} ━━━━━━━━━━━━━━━━━━━━━━━ Result: {messages: [msg1, msg2, msg3]} ↑ MERGE - Giữ hết!
✅ Lợi ích: Toàn bộ lịch sử được giữ nguyên!

🔧 6. Các Reducer Thông Dụng

Reducer Chức Năng Ví Dụ Use Case
operator.add Cộng/Nối 2 giá trị [1,2] + [3] = [1,2,3] Messages, logs, history
operator.or_ Logical OR {"a":1} | {"b":2} = {"a":1,"b":2} Merge dicts (Python 3.9+)
Custom function Logic tùy chỉnh lambda old, new: old if old else new Complex merge rules
None (default) Ghi đè old=5, new=10 → 10 Simple values (int, str, bool)

🎬 8. Flow Thực Tế: User Gửi 2 Tin Nhắn

Scenario: Clarification Flow

📩 Tin nhắn 1: "Mua đồ 100k"

⬇️
💰 Financial Agent: Cần clarification
# Financial agent node: return { "messages": [AIMessage( content="", tool_calls=[{ "name": "ask_clarification_tool", "args": {"question": "Mua đồ gì?"} }] )] } # operator.add được gọi tự động: new_messages = operator.add( [HumanMessage("Mua đồ 100k"), AIMessage("Routing...")], [AIMessage(tool_calls=[...])] ) # State sau Financial Agent: { "messages": [ HumanMessage("Mua đồ 100k"), AIMessage("Routing..."), AIMessage(tool_calls=[...]) ← Thêm vào cuối ], "clarification_needed": "Mua đồ gì?" ← Ghi đè }
⬇️
📩 Tin nhắn 2: User trả lời "Thực phẩm"
# API thêm HumanMessage mới: input_state = { "messages": [HumanMessage("Thực phẩm")], "clarification_needed": None } # LangGraph merge với state cũ (từ DB checkpoint): old_state = { "messages": [ HumanMessage("Mua đồ 100k"), AIMessage("Routing..."), AIMessage(tool_calls=[...]) ] } # Reducer merge: final_messages = operator.add( old_state["messages"], input_state["messages"] ) # State cuối: { "messages": [ HumanMessage("Mua đồ 100k"), AIMessage("Routing..."), AIMessage(tool_calls=[...]), HumanMessage("Thực phẩm") ← Merge thành công! ], "clarification_needed": None ← Ghi đè }
✅ Agent giờ có toàn bộ context:
  • Câu hỏi gốc: "Mua đồ 100k"
  • Clarification: "Mua đồ gì?"
  • Trả lời: "Thực phẩm"

→ Agent submit expense với category="Thực phẩm" thành công!

📊 10. Custom Reducer

Khi Nào Cần Custom Reducer?

Khi logic merge phức tạp hơn operator.add:

def merge_with_limit(old: List, new: List, max_len=10) -> List: """Merge nhưng giữ tối đa 10 items (giữ mới nhất)""" combined = old + new return combined[-max_len:] # Lấy 10 items cuối class State(TypedDict): messages: Annotated[ List[BaseMessage], merge_with_limit ]

Ví Dụ Custom Reducer Khác:

def deduplicate_merge(old: List[str], new: List[str]) -> List[str]: """Merge nhưng loại bỏ duplicate""" return list(set(old + new)) def smart_dict_merge(old: dict, new: dict) -> dict: """Merge dict với nested merge""" result = old.copy() for key, value in new.items(): if key in result and isinstance(value, dict): result[key] = smart_dict_merge(result[key], value) else: result[key] = value return result

❓ 11. FAQ

Q: Tại sao không dùng Reducer cho tất cả fields?

A: Không phải field nào cũng cần merge!
  • next: Chỉ cần giá trị mới nhất → Ghi đè
  • clarification_needed: Một câu hỏi tại một thời điểm → Ghi đè
  • messages: Cần toàn bộ lịch sử → Merge

Dùng Reducer khi không muốn mất dữ liệu cũ!

Q: operator.add hoạt động với type nào?

# ✅ List [1, 2] + [3] = [1, 2, 3] # ✅ String "Hello" + " World" = "Hello World" # ✅ Tuple (1, 2) + (3,) = (1, 2, 3) # ❌ Dict (dùng operator.or_ thay thế) {"a": 1} | {"b": 2} = {"a": 1, "b": 2}

Q: Reducer có ảnh hưởng đến performance không?

A: Ảnh hưởng rất nhỏ!
  • Reducer chỉ chạy khi có update
  • operator.add rất nhanh (O(n))
  • Trade-off xứng đáng để giữ data integrity

🎓 Bài Học Quan Trọng

Reducer là một trong những khái niệm cốt lõi giúp LangGraph quản lý State hiệu quả. Nó cho phép nhiều nodes cộng tác cập nhật cùng một field mà không làm mất dữ liệu.

Trong Expense Tracker, nhờ operator.add cho messages, agent có thể xử lý clarification flow phức tạp mà vẫn giữ nguyên toàn bộ context!
