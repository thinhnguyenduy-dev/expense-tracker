⚖️ So Sánh: Reducer vs Ghi Đè

Field Định Nghĩa Behavior Ví Dụ
messages Annotated[List, operator.add] MERGE (Cộng dồn) Node A: [msg1]
Node B: [msg2]
→ Kết quả: [msg1, msg2]
next Optional[str] OVERWRITE Supervisor: "financial_agent"
→ Dùng giá trị mới nhất
clarification_needed Optional[str] OVERWRITE Set "question" → Clear None
→ Control flow dừng/tiếp
categories List[str] (config) PASSED VIA CONFIG Fetch 1 lần ở API → Pass vào prompt
→ Không cần tool call

🎨 Minh Họa Reducer

# File: backend/app/agents/state.py messages: Annotated[List[BaseMessage], operator.add] ↓ # Cách hoạt động: old_state = {"messages": [msg1, msg2]} new_update = {"messages": [msg3]} # LangGraph tự động: final_state["messages"] = operator.add( old_state["messages"], # [msg1, msg2] new_update["messages"] # [msg3] ) # = [msg1, msg2, msg3] ✅ # Nếu KHÔNG dùng Annotated: final_state["messages"] = new_update["messages"] # = [msg3] ❌ (Mất msg1, msg2!)

📚 Tóm Tắt Key Points

1️⃣ State Chia Sẻ Toàn Graph

  • Tất cả nodes nhận cùng 1 AgentState
  • Mỗi node có thể đọc và cập nhật state
  • State được persist trong PostgreSQL (qua thread_id)

2️⃣ Reducer Pattern (operator.add)

  • Dùng cho field messages để giữ lịch sử conversation
  • Mỗi node thêm message mới → List tự động merge
  • Không bao giờ mất message cũ

3️⃣ Overwrite Pattern

  • Dùng cho metadata: next, clarification_needed
  • Giá trị mới ghi đè giá trị cũ
  • Phù hợp với dữ liệu tạm thời

4️⃣ Conditional Edges

  • Routing động dựa trên state
  • Ví dụ: Có tool_calls → Gọi tools, Không → Về supervisor
  • Hỗ trợ clarification flow (dừng → đợi user → resume)

5️⃣ Thread ID & Persistence

  • Mỗi conversation có thread_id unique
  • State lưu trong DB → Resume sau khi clarification
  • LangGraph tự động load state cũ khi invoke với cùng thread_id

6️⃣ Categories Optimization

  • Categories được fetch 1 lần ở API level
  • Pass vào config["configurable"]["categories"]
  • Agent nhận qua system prompt → Không cần gọi tool
  • Giảm 33% LLM calls, tăng 30% tốc độ

✅ Kết Luận

State (TypedDict) + Reducer Pattern cho phép:

  • ✅ Giữ lịch sử conversation đầy đủ (messages)
  • ✅ Chia sẻ context giữa các agents
  • ✅ Hỗ trợ clarification flow (pause/resume)
  • ✅ Cập nhật metadata linh hoạt (next, clarification_needed, ...)
  • ✅ Persistent state qua database
